# Contextual bandits for negotiation policy, deliberately not deep learning

Negotiation policy learning uses contextual bandits. With roughly 1,000 synthetic deals a
neural policy overfits and, worse, cannot explain why it offered a given discount — which
would break the "refuse with a stated reason" principle at exactly the point the video
depends on it. Choosing correctly over choosing impressively is itself the signal we want
to send to the panel.

## Consequences

Rules out a learned policy that needs more data than the swarm produces. Deep learning is
not banned from the project — it belongs in behavioural fraud detection, where there is
genuine sequence data and a real reason to learn.
